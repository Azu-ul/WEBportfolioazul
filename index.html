About

I turn an idea or a design into a clean, working website. I like the whole process, from structuring the layout to writing solid code and making sure the final result feels finished, not just functional.

My main stack is HTML, CSS and JavaScript, with React, React Native and TypeScript for more complex builds, and PHP, MySQL, Node.js and Express on the back end when a project needs it. I pick up new frameworks and languages fast.
